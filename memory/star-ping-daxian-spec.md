# 命宮定大限法（果老星宗・星平合參）

## 方法概述

又稱「星平小限法」「命宮分限法」。與子平八字的「月柱起大運」完全不同：
- **子平大運**：月柱起，看運勢起伏（運）
- **星宗大限**：命宮起，看肉身氣數壽元（壽）

**核心原則**：以「命宮」為基礎，取命宮**順數下一宮**為第一個大限，一律順時針走，每宮固定年限。

---

## 一、計算起點

- **命宮期**（非大限）：大運起運年齡 → 大運起運年齡 + 15年（命宮本身不算大限）
- **第一個大限**起始年齡 = 八字起運數 + 15
- **第一個大限宮位** = 命宮地支順時針下一宮

**範例**（命宮在寅，3歲起運）：
```
命宮期（寅）：3歲～18歲（非大限）
第1 大限（卯 = 相貌宮）：18歲～28歲
第2 大限（辰 = 福德宮）：28歲～39歲
第3 大限（巳 = 官祿宮）：39歲～54歲
第4 大限（午 = 遷移宮）：54歲～60歲
...
```

## 五、四大死亡關卡判斷（評分制）

### 關卡一：交度過宮（+30分）
當前虛歲距下一宮位交界 <= 1歲（容許度±1）。
- 交界點 = 各大限起始年齡（daYunStartAge+15, +25, +36, +51, +57, +66, +75, +79, +83, +88, +90.5）
- 古訣：「交度過宮如過關，不死也要脫層皮。」

### 關卡二：宮度克納音（+30分）
大限宮位五行**克**命主年柱納音五行。
- 五行相克：金克木、木克土、土克水、水克火、火克金
- 年柱納音最後一字為五行：海中金→金、大林木→木、爐中火→火、路傍土→土、澗下水→水
- 古訣：「限度克音因疾死，納音克限受熬煎。」

### 關卡三：行限落空亡（+30分）
當前大限宮位地支落入日柱旬空（用 `LfCalcDayEmpty(dStem, dBranch)`）。
- 古訣：「行限最忌落空亡，氣化為虛壽元終。」

### 關卡四：飛起吊沖（說明性輸出，不計分）
需配合流年太歲論斷，本節輸出提示供命理師參考：
- **沖（對宮）**：(當前大限地支序 + 6) % 12
- **吊（三方）**：(地支序 + 4) % 12 及 (+8) % 12
- 輸出：哪個流年地支最易引動此大限宮氣
- 古訣：「太歲進前飛神到，對宮沖激禍難逃。三方吊動煞星起，本宮起煞把魂消。」

### 計算邏輯
1. 用 `LfCalcMingGongBranch` 取得命宮地支
2. 命宮地支在12支中的序號 → 順時針+1 為第1大限地支
3. 各大限起始年齡 = `daYunStartAge + 15 + 累計年限`
4. 找當前大限（currentAge 落在哪個區間）
5. 計算四大關卡
6. 輸出報告節

### 不需新增 DB 表
所有計算均可用靜態資料 + 現有函數（`LfCalcMingGongBranch`, `LfCalcDayEmpty`）完成。

## 九、注意事項

- 若 luckCycles 為空，daYunStartAge 預設為 3
- 若 currentAge < daYunStartAge + 15，命主仍在命宮期（尚未進入大限），輸出提示
- 若 currentAge 超過 103.5，顯示「已超出大限週期」
- 若命宮地支計算失敗，整個區段不輸出
- 此法為輔助參考，報告中標注「供命理師審閱」
