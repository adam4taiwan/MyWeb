## 一、三層次主從架構（Slide 2）

```
Level 1  流年（氣候）= 最高主導，觸發具體事件
Level 2  大運（土壤）= 環境背景，決定10年基調
Level 3  命局（樹幹）= 被動根基，決定先天上限
```

**核心原則：外因（流年＋大運）透過內因（命局）起作用。階級不可逆。**

## 二、格局成就曲線類型（Slide 5）—— 目前缺少

### 判斷方式：以用神（yongShenElem）對應十神類型

| 用神十神 | 格局類型 | 成就曲線 |
|---------|---------|---------|
| 食神、正財、正官、正印 | 吉神格 | 穩健型：穩步向上，旺運有實效，逆運小波折 |
| 七殺、傷官、偏印、羊刃 | 凶神格 | 震盪型：旺運爆發力強，逆運震盪大，暴起暴落 |

### 用神十神判斷方式

用神五行（yongShenElem）→ 對應日主：
- 生日主之五行 = 印（正印/偏印，視陰陽）
- 同日主之五行 = 比劫（比肩/劫財）
- 日主生之五行 = 食傷（食神/傷官）
- 日主克之五行 = 財（正財/偏財）
- 克日主之五行 = 官殺（正官/七殺）

吉神 = 食神/正財/正官/正印
凶神 = 七殺/傷官/偏印（梟神）/羊刃（比劫類）

### 成就曲線對大運評等的詮釋修正

| 大運評等 × 格局類型 | 呈現說明 |
|-------------------|---------|
| 旺運 × 吉神格 | 穩健收成，努力必有結果 |
| 旺運 × 凶神格 | 爆發機會強，需大膽把握，但不持久 |
| 平運 × 吉神格 | 平穩耕耘，不急不徐 |
| 平運 × 凶神格 | 看似平靜實則暗流，謹慎行事 |
| 逆運 × 吉神格 | 小波折，守成即可，不傷根基 |
| 逆運 × 凶神格 | 大震盪，防大失，情緒起伏劇烈 |

|---------|---------|---------|

| 合財星（男）| 感情有緣，主動追求 |

### 衝的分類解析

| 衝哪個位 | 流年事件 |
|---------|---------|
| 衝日支（配偶宮）| 婚姻波折或搬遷 |
| 衝月支（格局根基）| 工作/家庭突變 |
| 衝羊刃位 | 突發血光/車禍/手術 |
| 衝桃花位 | 感情驟變、突發外遇、奔波 |
