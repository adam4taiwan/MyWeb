## 大運/流年空亡應用規則（待實作）

### 核心原則
- **大運地支落空亡**：該步大運所主事項力量虛浮，吉減力、凶減害
- **流年地支落空亡**：當年應事虛而不實，主要事項易名存實亡

### 判斷基準（重要）
- 大運/流年的空亡，**仍以命主日柱天干為基準**查旬空（後天空）
- 即：用 `CalcEmpty(dStem, dBranch)` 算出的 dayEmpty，判斷大運/流年地支是否落空

### 大運空亡論斷要點
1. **大運干支空亡** → 整段 10 年運勢虛浮，成就不易落實
2. **大運地支** 為命局用神之祿（長生/帝旺） → 空亡則用神力量大減
3. **大運地支** 為命局忌神之祿 → 空亡則凶性減輕（解凶）

### 流年空亡論斷要點
1. **流年地支落空亡** → 當年謀事易落空，財/官/婚 均難成
2. **流年為命主旺處逢空** → 當年無高峰，努力成效不顯
3. **流年為桃花（沐浴）逢空** → 感情虛花，難修成正果
4. **流年解空** → 大運地支與流年形成六合/沖 → 空亡力量減弱，事情反而成真

### 五行空亡意象（論大運/流年時活用）
| 五行 | 空亡意象 |
|---|---|
| 水空則流 | 居無定所、漂泊、財難聚 |
| 金空則鳴 | 名聲響亮，但實質有限 |
| 火空則明 | 光明磊落，但熱度不持久 |
| 木空則折 | 事業易折損，難長久 |
| 土空則陷 | 根基不穩，易有損失 |

### 解空四把鑰匙
逢值（流年走到空亡地支）、逢沖、逢六合、逢穿 → 可解空
