# 一柱論命算法架構（六步完整框架）

## 核心概念
以日柱（干支）+ 出生月支，自動產生六親吉凶及先天根基論斷。
參考書：一柱論命六十甲子.docx + 一柱論命點竅.docx（D:\命理知識庫\千里\）

## Step 1：有效日干（男女陰陽換位）

書中秘密：男女命取六親用干不同。

| 命主 | 日干性質 | 取六親用干 |
|------|---------|-----------|
| 男命 | 陽干（甲丙戊庚壬） | 本干 |
| 男命 | 陰干（乙丁己辛癸） | 換對應陽干 |
| 女命 | 陰干 | 本干 |
| 女命 | 陽干 | 換對應陰干 |

陰陽對應：甲↔乙、丙↔丁、戊↔己、庚↔辛、壬↔癸

```csharp
string GetEffectiveStem(string dayStem, int gender) {
    bool isYang = "甲丙戊庚壬".Contains(dayStem);
    var pair = new Dictionary<string,string> {
        {"甲","乙"},{"乙","甲"},{"丙","丁"},{"丁","丙"},
        {"戊","己"},{"己","戊"},{"庚","辛"},{"辛","庚"},{"壬","癸"},{"癸","壬"}
    };
    if ((gender == 1 && !isYang) || (gender == 0 && isYang))
        return pair[dayStem];
    return dayStem;
}
```

## Step 2：虛辰遁法 → 旬中地支定六親位置

每個日柱屬於某個甲子旬（10干×10支循環）。
旬中每個天干所坐的地支 = 該六親的「定位地支」。

- 旬首 = 包含日柱的甲X干支
- 旬展開：旬首起，10干依序配10支
- 空亡：旬中未覆蓋的2個地支

**虛辰遁法**：八字中若某六親天干不出現，向旬首求，取旬中該干所坐地支為六親位。

例：壬子日（甲辰旬）
甲辰、乙巳、丙午、丁未、戊申、己酉、庚戌、辛亥、壬子、癸丑
空亡：寅、卯

## Step 3：六親強弱

### A: 六親干在其旬中地支的十二長生 → 強弱
```
六親干 × 六親坐支 → 長生位
旺(長生/冠帶/臨官/帝旺) → 六親有力
弱(死/墓/絕) → 六親緣薄刑剋
```

### B: 日支 vs 六親坐支 → 關係吉凶
| 關係 | 斷義 |
|------|------|
| 六合/三合 | 六親親密相助 |
| 沖 | 分離刑剋 |
| 害 | 暗傷隱患 |
| 刑 | 紛爭官非 |

## Step 4：十神非六親象意

每個十神同時代表人事（六親）和命理象意：

| 十神 | 非六親象意 |
|------|-----------|
| 正財/偏財 | 財運、積財能力 |
| 正官/七殺 | 官職、名譽、競爭壓力 |
| 正印/偏印 | 學業、文書、貴人、技藝 |
| 食神 | 口福、才藝、壽元 |
| 傷官 | 才華、口才、官運受阻 |
| 比肩 | 朋友合夥、平輩助力 |
| 劫財 | 破財、競爭損耗 |

十二長生位決定各象意的強弱。

---

## Step 5：月令對日干喜忌 → 先天根基

月令五行 vs 日干五行關係：

| 月令 vs 日干 | 關係 | 日主狀態 |
|------------|------|---------|
| 同五行月 | 比劫同氣 | 身旺 |
| 生我月 | 印生日主 | 偏強 |
| 我生月 | 食傷洩氣 | 偏弱 |
| 我剋月 | 財耗日主 | 偏弱 |
| 剋我月 | 官殺制身 | 弱 |

喜忌方向：
- 身強 → 喜食傷、財、官殺；忌比劫、印
- 身弱 → 喜印、比劫；忌食傷、財、官殺

---

## Step 6：旬中干支 vs 日柱互動

旬中每個干支與日柱（日干+日支）同時分析：

1. 天干關係：合/沖/剋/生
2. 地支關係：六合/三合/沖/害/刑
3. 六親識別（Step 2）
4. 喜忌（Step 5）
5. 組合斷義

**天剋地沖 = 最烈**（如甲庚+子午同時沖）

例：甲子日，申月（身弱），庚午旬中
- 天干：甲庚沖（忌神沖日主）
- 地支：子午沖
- 六親：庚=兒子（七殺 for 甲男）
- 斷：天剋地沖，兒子緣薄難得，競爭壓力極大
