## 功能一：八字空亡（旬空）

**狀態：[x] 已完成（2026-04-30）**

### 實作說明
- 方法：`LfKongWang(yStem, yBranch, mStem, mBranch, dStem, dBranch, hStem, hBranch)`
- 規則：年/月/時柱以日柱天干查旬空；日支以年柱天干查旬空
- 算法：startBranchIdx = (branchIdx - stemIdx + 12) % 12；空亡 = (start+10)%12、(start+11)%12
- 整合位置：LfBuildYudongziReportV2 第三章，納音論斷之後，標籤【空亡論斷】
- 輸出：年/月/日支/時柱宮位各一條（祖宗/父母/夫妻/子女緣份）+ 坐空天干補充

### 說明
- 六十甲子每旬有兩個地支空亡（旬空）
- 依年/月/日/時柱地支逐一判斷是否落空
- 落空的柱位，其六神力量大減，應事能力弱化

### 開發要點
- [ ] 建立旬空對照表（甲子旬→戌亥空、甲戌旬→申酉空 … 共6旬）
- [ ] 根據日柱干支找出所屬旬，確定空亡地支
- [ ] 判斷年/月/日/時四柱哪些地支落空
- [ ] 輸出文字：「X柱落空亡，X神力量虛浮，X方面易有名無實之象」
- [ ] 大運流年如行至旬空之地支：吉減力、凶減害（須說明）
- [ ] 整合位置：建議放在第三章或第五章用神喜忌之後

## 功能二：八字納音

**狀態：[x] 已完成（2026-04-29）**

### 實作說明
- 方法：`LfNaYin(yStem, yBranch, mBranch, dStem, dBranch, hBranch)`
- 資料來源：師傳.doc 七章（Python 萃取 UTF-16LE）
- 整合位置：LfBuildYudongziReportV2 第三章，十干象法之後，標籤【納音論斷】
- 四柱各出一項：
  - 年柱：Ch.1(五行命名原理) + Ch.4(生肖+納音特質) + Ch.3(年命推算，跳過與Ch.1重疊首句)
  - 月柱：Ch.5 年生肖×月支（143/144）
  - 日柱：Ch.2(納音細注) + Ch.6 年生肖×日支（141/144）
  - 時柱：Ch.7 年生肖×時支（142/144）
- 缺失 entries（原文無對應）：辰_酉、巳_酉、申_寅、戌_戌、卯_亥、戌_戌

### 說明
- 六十甲子每對干支有對應納音五行（如甲子乙丑→海中金）
- 納音可補充說明命主的先天稟賦、體質、才華偏向
- 傳統用於輔助日柱判斷，與正五行互為參照

- [ ] 取日柱納音（主）＋年柱納音（輔）
- [ ] 輸出文字：納音名稱 + 1-2句特質論斷

## 功能五：十干象法

**狀態：[x] 已完成（2026-04-29）**

### 說明
- 十天干各有其象：甲→大樹/棟樑、乙→花草/藤蔓、丙→太陽/火炬、丁→燈燭/星火...
- 透過日主天干的「象」，對命主性格、形象、職業方向做更生動的論斷
- 結合月令（得令/失令）判斷象的強弱

### 實作說明
- 方法：`LfShiGanXiangFa(dStem, mBranch)`
- 資料來源：十干象法.docx（Python zipfile+XML 萃取）
- 資料：`stemBase`（10 干基礎描述）+ `monthDesc`（120 組干×月）
- 整合位置：LfBuildYudongziReportV2 第三章，標籤【十干象法】
