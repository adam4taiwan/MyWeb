# 五行計分方法論（LfCalcWuXingMatrix）

## 計分公式

### 天干（各 10 分）
```
天干得分 = 10 × LfSeasonMult(元素, 季節) × LfGetStemRootMult(元素, 四柱地支)
```

### 地支（各 10 分，月支 30 分）
```
地支得分 = 基礎分 × 藏干比例(ratio) × LfSeasonMult(元素, 季節) × LfGetBranchMult(地支, 四柱) × dispersionFactor
```
- 非月支：基礎分 = 10
- 月支：基礎分 = 30，dispersionFactor = 1藏干1.0 / 2藏干0.85 / 3藏干0.75

最終：各元素原始積分 ÷ 全部總分 × 100 = 五行百分比

## 季節乘數（LfSeasonMult）旺相休囚死

旺=1.6, 相=1.2, 休=1.0, 囚=0.5, 死=0.5

| 元素 | 春(木旺) | 夏(火旺) | 秋(金旺) | 冬(水旺) | 四季(土旺) |
|------|----------|----------|----------|----------|------------|
| 木 | 旺 1.6 | 休 1.0 | 囚 0.5 | 相 1.2 | 死 0.5 |
| 火 | 相 1.2 | 旺 1.6 | 死 0.5 | 囚 0.5 | 休 1.0 |
| 土 | 囚 0.5 | 相 1.2 | 休 1.0 | 死 0.5 | 旺 1.6 |
| 金 | 死 0.5 | 囚 0.5 | 旺 1.6 | 休 1.0 | 相 1.2 |
| 水 | 休 1.0 | 死 0.5 | 相 1.2 | 旺 1.6 | 囚 0.5 |

季節判斷（LfGetSeason）：寅卯=春, 巳午=夏, 申酉=秋, 亥子=冬, 辰戌丑未=四季

## 天干通根乘數（LfGetStemRootMult）

天干元素在任一地支藏干中找到同元素時加乘，取四柱地支中最高值：

| 通根類型 | 乘數 | 條件 |
|----------|------|------|
| 通本氣 | 1.5 | 藏干index=0（主氣，ratio最高） |
| 通中氣/餘氣 | 1.3 | 藏干index≥1 |
| 無根 | 1.0 | 四柱地支均無此元素 |

比較元素（非干支直字），如丙丁同屬火，均可通午中丁火之本氣（1.5x）。

## 比印陣（身強弱判定）

```
比印陣% = wuXing[日主元素] + wuXing[印星元素]
洩克陣% = 100 - 比印陣%
```

身強弱分級（LfGetBodyStrengthLabel）：
| 比印陣% | 判定 |
|---------|------|
| ≥ 70% | 身強（極強） |
| 60~69% | 身強 |
| 45~59% | 中和 |
| 30~44% | 身弱 |
| < 30% | 身弱（極弱） |

## 從格判定條件（LfDetectGeJuAndYongShen）

**觸發條件（需同時滿足）：**
1. 比印陣 bodyPct ≤ 20%
2. 洩克三方（官殺+財+食傷）合計 oppPct ≥ 70%
3. **【前置排除】天干無有根的比劫/印** ← 2026-04-26 加入

**前置排除邏輯：**
年干、月干、時干中，若有比肩/劫財/正印/偏印其中之一，且其五行在四柱任一地支藏干中出現（通根），則強制排除從格，改判正格。

```csharp
bool hasRootedBiJiYin = new[] { yStem, mStem, hStem }.Any(s => {
    string ss = LfStemShiShen(s, dStem);
    if (ss != "比肩" && ss != "劫財" && ss != "正印" && ss != "偏印") return false;
    string sElem = KbStemToElement(s);
    return allBranches.Any(b =>
        LfBranchHiddenRatio.TryGetValue(b, out var h) && h.Any(hh => KbStemToElement(hh.stem) == sElem));
});
```

**從格細分：**
- oppPct ≥ 70 時，官殺最重 → 從殺格
- 財最重 → 從財格
- 食傷最重 → 從兒格

## 典型案例（2026-04-26 驗證）

戊午 辛酉 丙戌 丁酉（女命 1978/9/21 18:00）
- 日干：丙(火)，月令：酉(秋)
- 火在秋 = 死(0.5)，金在秋 = 旺(1.6)，月支酉 30基礎分
- 丁(時干) 通根 戌中丁(餘氣,index2) → hasRootedBiJiYin=true → 排除從格
- 結果：正財格，比印陣17%，身弱（極弱）
