# 大運命書 v2 規格（feature/daiyun-v2 分枝）

> 原版保留在 main 分枝，v2 在 feature/daiyun-v2 開發
> 若結果不理想可切回 main

---

## v2 核心改善方向

1. **移除報告正文數字分數**（保留內部計算，不對客人顯示）
2. **命理師語氣**：直接對命主說話，不用技術標注
3. **八字+紫微交叉敘事**：兩者同指 → 強力論斷；單方 → 僅列觀察
4. **依年齡段自動聚焦**：不同人生階段展開不同核心議題
5. **具體行動建議**：最佳年份做什麼、凶年怎麼防守

## 報告章節結構

### 第一章：命主概況與格局
- 四柱、格局、用神（文字論斷，不顯示分數）
- 當前大運位置
- 命格先天基調（一句話定性：此命適合穩中求勝 / 大起大落型 / 貴人助力型...）

### 第二章：大運干支雙向論斷
- 八字面：此段大運天干地支喜忌影響
- 紫微面：大限宮位星曜格局
- **【交叉結論】**：
  - 兩者同指吉 → 「此段大運八字與星盤同時有利，可主動出擊」
  - 兩者同指凶 → 「此段需全面守成，八字與星盤均有壓力」
  - 一吉一凶 → 「此段有機有險，需看具體方向」

### 第三章：[人生階段] 重點分析
（依命主分析起始年齡自動切換，詳見 daiyun-v2-lifestage-topics.md）

#### 15–20歲版
- 學業才能方向（八字食傷/印綬格局）
- 貴人助力時機（紫微命宮/父母宮）
- 努力是否有回報（大運喜忌）

#### 20–40歲版（最完整）
- **職業方向**：公務/私企/創業/自雇，適合行業
- **發展格局**：國內/國外，打拼期/收成期時間軸
- **感情婚姻**：何時遇對象，早婚/晚婚，適合對象類型
- **財富起步**：正財/偏財格局，置產時機
- **子女緣份**：適合生育時機，子女緣深淺

#### 40–55歲版
- 事業突破或守成判斷
- 財富置產最後時機
- 婚姻穩定性（中年危機）
- 子女教育與出路
- 健康臟腑預警

#### 55–70歲版
- 事業退場時機
- 財庫守護（防詐騙/破財）
- 子女依靠評估
- 身體關卡年份

#### 70歲以上版
- 壽元與健康關卡
- 子孫緣與晚年陪伴
- 財產傳承安排

### 第四章：健康與意外（全年齡共用）
- 先天體質弱項（五行對應臟腑）
- 大運期間健康注意面向
- 意外/官司/車關風險年份（有則列，無則省略）
- 小人類型與防範（忌神十神對應）

### 第五章：流年重點標注
- **格式改變**：不逐年列出，改為「重點年份」模式
- 大吉年（2-3個）：具體說明為何吉，適合做什麼大事
- 大凶年（2-3個）：具體說明風險在哪，如何防守
- 其餘年份：一句話帶過（平順推進 / 小有波折但無礙）

### 第六章：趨吉避凶行動建議
- 整體基調（這段大運命主應該採取什麼姿態）
- 貴人方向（哪個方位/生肖/類型的人可以幫助）
- 最佳把握年份 + 具體行動建議
- 需謹慎年份 + 具體防守策略

## 技術實作規劃

### 新增/改寫方法

| 方法 | 說明 |
|------|------|
| `DyGetLifeStage(age)` | 回傳年齡段：teen/young/adult/middle/senior/elder |
| `DyBuildLifeStageSection(stage, ...)` | 依年齡段產出第三章內容 |
| `DyBuildCareerSection(...)` | 職業方向論斷（20-40專用） |
| `DyBuildRelationshipSection(...)` | 感情婚姻論斷 |
| `DyBuildWealthSection(...)` | 財運/置產論斷 |
| `DyBuildHealthSection(...)` | 健康意外（共用） |
| `DyBuildKeyYears(...)` | 流年重點年份（取代逐年模板） |
| `DyBuildReport_V2(...)` | v2 整合報告（舊版保留不動） |

### 現有方法保留
- `DyCalcFlowYearBaziScore` — 保留計算，但不輸出分數到報告
- `DyCrossClass` — 保留邏輯，轉換為文字敘事
- `DyCalcZiweiScore` — 保留計算

### 端點
- 新增 `analyze-daiyun-v2`（測試用）
- 或在 `analyze-daiyun` 加 `?v=2` 參數切換
- 確認 v2 穩定後再合併取代

## 注意事項
- 所有論斷語氣：命理師直接對命主說話
- 禁止出現：「評分75分」「屬喜用五行」「交叉矩陣」等技術詞
- 八字+紫微必須交叉驗證，單方向的論斷降格為觀察
