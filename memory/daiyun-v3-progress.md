## 已解決的 Bug 清單

### Ch.3 矛盾（已修）
- **原因**：`lcBaseTone3` 用 "大吉/吉/平" 判斷，`dyGood3/dyBad3` 用 "大吉/吉/中吉 / 大凶/凶/小凶"，條件不同
- **修法**：`lcBaseTone3` 改用與 `dyGood3/dyBad3` 完全相同的條件：
  ```csharp
  lcLevel3 is "大吉" or "吉" or "中吉" → "整體屬順境..."
  lcLevel3 is "大凶" or "凶" or "小凶" → "整體壓力偏大..."
  else → "整體吉凶各半..."
  ```

### Ch.6 各年重複（已修）
- **原因**：感情/財務/凶年事業 用 stage switch，同一年齡段內所有年份相同
- **修法**：改用 `d.flStemSS` switch，每個十神都有獨立文字
  - 好年感情：食神/傷官/正印/偏印/比肩/劫財/正官/七殺 各不同
  - 好年財務：正官/七殺/傷官/食神/正印/偏印/比肩/劫財 各不同
  - 凶年事業：正官/七殺/傷官/劫財/比肩 各不同
  - 凶年感情：正官/七殺/傷官/劫財比肩/偏印 各不同
  - 凶年財務：正官/七殺/劫財比肩/傷官/偏印正印 各不同

### 紫微 KB 文字品質（已修）
- **DyGetDecadeSiHuaNote 後綴移除**：`帶入口福以X為主` / `化入壓力以X為主` 整段移除
- **CleanZiweiDesc 過濾**：
  - 開頭過濾：`倘` / `最好` / `如格局` / `如`
  - 內容過濾：`逢沖破` / `最好該宮` / `不主財` / `不主貴` / `在財宮不能說` / `很可惜` / `喜與命身相合` / `影響一個人的相貌` / `奉子命結婚` / `代溝之象`
  - 每段最多保留前 2 句

### 六合描述 bug（已修）
- **原因**：`LfBranchEvents` 輸出 "與卯六合火"，`.Replace("六合", "與命局合化，")` 產生 "與卯與命局合化，火"
- **修法**：改為 `.Replace("六合", "六合，合化")` → "與卯六合，合化火"
