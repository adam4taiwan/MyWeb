## 一、五行計分：四階梯算法

### Tier 1：天干透干
每支天干固定 +10 分，不乘季節係數。

### Tier 2：地支通根
- 地支本氣（hiddenStems[0]）：+15 分
- 餘氣藏干（hiddenStems[1+]）：各 +5 分

### Tier 3：相鄰地支拱合/半三合（僅限相鄰柱，+12 分）
| 相鄰地支組合 | 注入五行 |
|---|---|
| 子+寅 | 土（拱丑） |
| 寅+辰 | 木（半三合拱卯） |
| 亥+未 | 木（半三合拱卯） |
| 巳+未 | 火（拱午） |
| 寅+戌 | 火（半三合拱午） |
| 申+戌 | 金（拱酉） |
| 巳+丑 | 金（半三合拱酉） |
| 申+辰 | 水（半三合拱子） |
| 亥+丑 | 水（拱子） |

只看相鄰柱對（年月、月日、日時），不看隔柱。

### Tier 4：月令司令加成
月支本氣所屬五行的累計分數 × 1.3（僅該五行，其他不動）。

### 輸出
返回原始分數 dict（非百分比），供後續使用。

## 二、身強弱判定（六級制，2026-08-30 定案）

```
bodyPct = (自身五行 + 印星五行) / 全部五行總分 × 100
```

| 範圍 | 標籤 | 用神候選邏輯 |
|---|---|---|
| >= 70% | 極強 | 取制洩（官財食） |
| 55-69% | 偏強 | 取制洩，考量格局 |
| 45-54% | 中和 | 依格局定，忌神看官殺 vs 印誰重 |
| 30-44% | 偏弱 | 取生扶（印比） |
| 20-29% | 身弱 | 取生扶（印比） |
| < 20% | 極弱 | 近從格，取生扶或考慮從格 |

**前後端統一使用此閾值**（Ecanapi `LfGetBodyStrengthLabel` + jiliang `page.tsx` bodyLabel 兩邊同步）。

## 三、格局判定優先順序（外格優先原則）

```
① 化氣格（最高優先，直接 return）
   條件：日干×月/時干 天干合化 + 月令支持化神 + 無破格元素

② 五行從旺外格（可覆蓋建祿格）
   曲直 / 炎上 / 稼穡 / 從革 / 潤下
   條件：日主五行 + 月令 + 地支組合 + 無剋元素（藏干 ratio>=0.3 才算破格）

③ 從格（isJianLuMonth=true 時被阻擋，不可覆蓋祿刃格）
   從殺格 / 從財格 / 從兒格：bodyPct <= 20 + 日主無中根（ratio>=0.3）通根 + 對立 >= 70%
   從旺格：bodyPct >= 80 + 同元 >= 75% + 無強破格干

④ 建祿格 / 月刃格（外格，優先於八內格）
   - 十干建祿/月刃表：甲寅、乙卯、丙巳、戊巳、丁午、己午、庚申、辛酉、壬亥、癸子
   - 月刃：甲卯、丙午、戊午、庚酉、壬子
   - 或月支本氣 = 比劫（比肩→建祿、劫財→月刃）

⑤ 八內格（四則取法，內格）
   Rule 1：月支本氣透干 → 取該格
   Rule 2：本氣不透，取透干藏干（優先得令 siLingStem）
   Rule 3：無透干，取 siLingStem 或 ratio 最高非比劫藏干
   （比劫不取格，排除）
```

### 格局名稱不因刑沖改變

月支被刑/沖時，格局名稱維持，但在 yongReason 中補標注：
- 月支被六沖：「格局月令受沖，用神須從其他地支求根」
- 月支被三刑：「格局月令受刑，根基不穩」

## 四、用神三Tier篩選（通根為實原則）

**取格確定後，從 LfGetYongShenCandidates 候選中依三Tier選用神：**

```
Tier 1（最優）：有根 + 不空亡 + 不沖 + 不刑害  → BestByRank(旺相休囚死排序)
Tier 2：        有根 + 不空亡 + 不沖（有刑/害降級）
Tier 3：        有根但空亡
Default：        全無根 → 旺相排序取最佳
```

**空亡計算**：
- 年/月/時支空亡：以日柱天干起旬計算
- 日支空亡：以年柱天干起旬計算

## 七、刑沖合害修正（LfApplyXingChongHeHai）

### 六沖（本氣 ±）
| 組合 | 克方本氣 | 被克方本氣 |
|---|---|---|
| 子午、巳亥 | -30% | -60% |
| 寅申、卯酉 | -30% | -60% |
| 辰戌、丑未 | 各-35%（土土互沖） |

### 三刑（各支本氣）
- 寅巳申（無恩之刑）、丑戌未（持勢之刑）：出現 2 支以上各 -35%
- 子卯相刑：各 -30%

### 六合合化
合化條件：月令月支支持化神五行

**距離係數（i1, i2 為柱序 0=年 1=月 2=日 3=時）**：
```
距離 = |i1 - i2| - 1
  0（相鄰柱）：inject = 30 × 1.35 = 40.5；各損本氣 × 80%
  1（隔1柱）：inject = 30 × 1.00 = 30.0；各損本氣 × 50%
  2（隔2柱）：inject = 30 × 0.70 = 21.0；各損本氣 × 30%
```

**合而不化**（月令不支持化神）：
```
  相鄰：各 × 0.80
  隔1：各 × 0.90
  隔2：各 × 0.95
```

### 六害（只傷藏干餘氣）
各藏干 hiddenElements 各 × -25%

## 八、財官格局等級（LfCalcFortuneLevel）

### 財官分數計算
**身強（bodyPct >= 50%）**：
```
wealthScore = 財星分 × 0.75 + 食傷分 × 0.25
govScore    = 官殺分 × 0.75 + 財星分 × 0.25
```

**身弱（bodyPct < 50%）**：
```
wealthScore = 財星分 × 0.60 + 印星分 × 0.25 + 比劫分 × 0.15
govScore    = 官殺分 × 0.60 + 印星分 × 0.40
```

### 等級映射
| 分數 | 等級 | 財富定位 | 官貴定位 |
|---|---|---|---|
| >= 80 | 9級 | 頂級（百億至千億） | 國家元首、國際領袖 |
| >= 60 | 7級 | 特級（億至數十億） | 部會首長、地方諸侯 |
| >= 40 | 5級 | 高級（財務自由） | 中高階主管、公協理事 |
| >= 20 | 3級 | 中級（穩定中產） | 專業講師、基層幹部 |
| >= 0 | 1級 | 初級（小康自足） | 平民百姓、悠閒自適 |

## 九、動態歲運評分

### 動態年分計算
```
動態分 = 先天原始分 + 大運干(+10) + 大運支本氣(+15) + 大運支藏干(各+5)
                     + 流年干(+10) + 流年支本氣(+15) + 流年支藏干(各+5)
```

### 動態拱會加分（+20）
大運支或流年支與命局任一支形成三合/方局 → 目標元素 +20

### 流年天干觸發加成
流年天干五行 = 命局某地支本氣五行 → 該五行 × 1.5

## 十二、命書文字展示規範

### 五行分布
- 顯示四階梯原始分（含 Tier 3，不含刑沖合害）轉百分比
- 格式：`木XX%(財) 火XX%(官) 土XX%(印) 金XX%(比) 水XX%(食)`

### 比印陣
- 比印 = (比劫分 + 印星分) / 總分
- 基於原始分（不含刑沖合害修正）

### 財官格局等級（新增段落，所有命書）
```
【先天財富格局】X級（社會定位描述）
  財星(五行)佔命局XX%，先天承載：XX分
  資產規模參考：XXX

【先天官貴格局】X級（社會定位描述）
  官星(五行)佔命局XX%，先天承載：XX分
  社會地位參考：XXX
```

### 月支刑沖標注（新增）
月支被沖/刑時，在格局說明後加：
- 六沖：「月令受沖，格局力薄，用神須從其他地支求根」
- 三刑：「月令受刑，根基不穩，宜藉大運補救」
