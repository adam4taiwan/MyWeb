# 流年命書 - 大運/流年/流月 三層分析方法論

## 核心架構（由大到小）

### 第一層：大運（定大方向）

- 天干管前5年，地支管後5年
- **喜用大運**：
  - 優先查大運干支引動八字四柱哪個干/支的刑沖害合
  - 若有刑沖害合 → 對應宮位（年柱/月柱/日柱/時柱）吉事啟動
  - 若無刑沖害合 → 以大運干支在四柱中「得氣」（旺相）論輕微助力
- **忌神大運**：
  - 同上查刑沖害合 → 對應宮位凶事、破壞、動盪
  - 若無 → 以失氣（休囚死）論壓制

### 第二層：流年（主事+鬧強弱）

- **流年天干十神主事**：決定今年「主要在哪件事上發生」
  - 正官/七殺 → 職場、官方、管束
  - 正財/偏財 → 財運、投資、物質
  - 正印/偏印 → 學習、長輩、思慮
  - 食神/傷官 → 才藝、表達、突破
  - 比肩/劫財 → 同儕、競爭、自我
- **鬧強弱** = 流年干支是喜用還是忌神
  - 喜用 → 今年主事領域吉（具體正面展開）
  - 忌神 → 今年主事領域凶（具體負面困境）
- **流年地支引動命局**：
  - 流年地支與四柱+大運地支的刑沖害合
  - 命中哪個宮位（年/月/日/時柱）→ 對應六親/人生領域受影響
  - 喜用年 → 被引動宮位吉事（升遷、得財、婚姻等）
  - 忌神年 → 被引動宮位凶事（破財、官非、感情摩擦等）

### 第三層：流月（影響流年，不獨立成事）

**重要原則：流月不獨立論事，只影響流年干支的主事變吉/變凶**

- **流月天干**：強化或壓制流年天干十神主事
  - 流月干生流年干 → 本月流年主事更旺（加分）
  - 流月干剋流年干 → 本月流年主事受壓（扣分）
  - 流月干同流年干五行 → 並力（喜用→更吉，忌→更凶）
- **流月地支刑沖害合破**：引動流年地支 → 使流年主事在本月爆發
  - 流月支沖流年支 → 流年主事在本月「動」最大，吉凶都爆發
  - 流月支合流年支 → 流年主事在本月「成」，喜用則成事，忌神則合絆
  - 流月支刑流年支 → 流年主事在本月「鬧」，摩擦衝突或壓力集中
  - 流月支害/破流年支 → 流年主事受小衝擊，有暗損或計劃折扣
- **神煞**：
  - 月份若逢特定神煞（天德/月德/驛馬/桃花等）額外加減分
  - 結合流年主事論斷（驛馬+遷移主事 → 本月出行/移動最強）

## 輸出原則（重要）

1. **大運**先論定方向，流年/流月只是時間點上的精確化
2. **流年天干十神**是主角，每個月都圍繞同一個主事
3. **流月**改變的是「這個主事在本月是吉是凶/是否爆發」
4. 避免每月都說不同的主事（那是流年分析，不是流月分析）
5. 輸出格式：「本月[流月干支引動流年]，[流年主事]在本月[吉凶程度]，宜[建議]」

## 範例（流年丙午·正官·忌神）

- 全年主事：正官（職場管束/官方壓力）是今年主軸，且為忌神
- 寅月庚寅：庚剋丙（壓制正官），寅沖年支（若年支申）→ 本月職場壓力最重，宜避衝突
- 卯月辛卯：辛剋丙，卯若合戌 → 本月合住某宮位，壓力暫緩但有拖延
- 戌月戊戌：戊生丙（助力），戌合卯（若卯為月支）→ 本月職場稍有緩解，長輩有助
