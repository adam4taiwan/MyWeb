# 人生各階段論命 — 補充方法論（5項缺口）

## 1. 小人類型

### 八字判定
- 忌神 × 十神 在四柱呈現
  - 年柱 → 長輩、父母型小人
  - 月柱 → 同輩、同事、同學、兄弟姐妹型小人
  - 日柱 → 自身判斷易錯、防伴侶
  - 時柱 → 晚輩、子女型小人
- 十神類型對應小人性質（比劫=同業/競爭；官殺=上司/公權力；印梟=長輩/顧問）

### 小人生肖勿近
- 八字中忌神地支 → 對應生肖即為小人生肖

### 事業/朋友不宜交往
- 出生年支對宮生肖（六衝對宮）：
  子↔午、丑↔未、寅↔申、卯↔酉、辰↔戌、巳↔亥

---

## 2. 官司輸贏

### 身弱命主
- 忌神官殺 = 官司起因
  - 八字有食傷制官殺 → 問題不大（有解）
  - 八字無食傷 → 情況嚴重

### 身強命主
- 忌神印梟 = 文書受害（合約/公文/名聲）
  - 八字有財制印 → 問題不大（有解）
  - 八字無財 → 情況嚴重

### 柱位對應涉案對象
- 年柱 → 長輩、父母相關
- 月柱 → 同輩、同事、兄弟姐妹相關
- 日柱 → 自身判斷錯誤、伴侶相關
- 時柱 → 晚輩、子女相關

---

## 3. 車關時機

### 先天條件
- 八字地支有官殺，且為寅申巳亥（四驛馬）→ 先天有車關傾向

### 引動時機
- 大運或流年沖合該官殺地支之年 = 車關發生時機
- 例：八字申金官殺 → 流年寅年（寅申沖）引動

## 5. 海外發展條件

### 八字判定
- 寅申巳亥在年柱或月柱，且為喜用神
  - 移居/移民 → 印梟為喜用
  - 工作/派駐 → 官殺為喜用

### 紫微斗數判定
- 遷移宮：化祿或化科，且宮支為寅申巳亥 → 出國有利
- 田宅宮：宮支為寅申巳亥 + 化祿或化科 → 移民傾向

### 兩者交叉
- 八字喜用 + 紫微遷移/田宅有祿科 = 確立論斷可出國/移居
