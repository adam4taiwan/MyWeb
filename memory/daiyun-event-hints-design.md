# 大運生活事件提示設計文件

## 核心思想

**喜忌決定運勢方向 → 財% 決定財富操作建議 → 官% 決定職場建議 → 年齡段決定生活議題**

- 用神/喜神大運：運勢背景順，努力有成效，機遇把握成功率高
- 忌神大運：逆風期，同樣的努力結果打折，要守成不要躁進
- 財%（財富兌現率）：這段大運財星能發揮多少，決定「靠什麼賺錢/財務建議」
- 官%（官貴兌現率）：這段大運官星能發揮多少，決定「職場升遷/地位建議」
- 年齡段：決定這段期間「人生真正在面對什麼問題」

## 年齡段與人生實際議題

### 成長奠基期（0-15歲）
- 家庭財力影響成長環境（財% = 家境）
- 學業基礎建立（官% = 學業競爭力）
- 父母給的資源與壓力（大運喜忌 = 貴人/阻力來源）
- 性格潛質顯現期

### 奠基期（15-20歲）
- 高中→大學升學方向（理工/文商/藝術）
- 考試競爭力（官% 高 → 考試型；低 → 技職/才藝型）
- 有無貴人老師引導（大運是否喜用）
- 家庭資源是否支援升學（財% = 家境）
- 感情萌芽期，對象類型初現

### 決策期前段（20-30歲）
- 畢業求職方向：公職/大企業 vs 業務/創業/自雇（官% vs 財%）
- 技能積累方向（食傷/財官 十神）
- 感情開始認真（男命財星旺 → 桃花佳；女命官星旺 → 緣分成熟）
- 結婚時機研判（大運喜用 + 峰年）
- 買車/租房/小資產起步

### 決策期後段（30-40歲）
- 升遷跳槽機會（官% 決定升遷力道）
- 創業評估（財% 高 + 大運喜用 → 適合出去創業）
- 買房置產（財%高 + 峰年）
- 生育時機（子女宮 + 此段大運）
- 合夥投資是否適合

### 收成守成期（40-55歲）
- 事業是否還有突破機會，或已到頂轉守（官%）
- 置產/投資最後黃金期（財% + 峰年）
- 婚姻穩定性：中年危機風險（大運沖日支）
- 子女教育、出路（子女十神）
- 健康第一個大關（五行偏枯對應臟腑）
- 財庫守護能力（財%低 + 逆運 → 嚴防破財）

### 交棒期（55-70歲）
- 退休時機研判（官%持續低 → 該退場了）
- 財庫守護（防詐騙、防破財、不宜風險投資）
- 子女靠不靠得住（六親十神）
- 身體健康成為主要關卡
- 第二春事業（顧問/講學/傳承）

### 安樂期（70歲以上）
- 壽元與健康（五行偏枯 + 大運）
- 子孫陪伴與依靠
- 財產傳承安排
- 心靈安頓（宗教/修行）

## 財官% 閾值定義

| 範圍 | 財富解讀 | 官貴解讀 |
|------|----------|----------|
| ≥ 80% | 財運極佳，積極創造財富 | 官運強，升遷機遇明顯 |
| 60-79% | 財運不錯，主動出擊可收成 | 官運尚佳，有表現機會 |
| 40-59% | 財運普通，穩健理財 | 官運普通，靠積累不靠機遇 |
| < 40% | 財運弱，守成防破財 | 官運弱，升遷困難，不宜追求 |

## 喜忌影響層

- **用/喜大運**：
  - 努力有成效，機遇把握率高
  - 決策期：感情婚姻事業雙順
  - 投資出手時機佳
- **忌大運**：
  - 逆風期，守成為主
  - 感情容易波折，重大決策緩行
  - 財務謹慎，不宜大額借貸
- **大運沖日支**：
  - 婚姻、健康是主要風險點
  - 移居搬遷可能

## getDaYunEventHints 函數邏輯

輸入：`DaYunStat` + `apiData`（用喜忌/性別/格局）+ `chart`（十神）

輸出：`string[]`（2-3 句具體生活事件提示）

### 生成規則

每條提示由以下三層合成：
1. **年齡段議題**（這段在面對什麼）
2. **財官%閾值**（財官表現如何）
3. **喜忌方向**（順境或逆境）

峰值年（wPeakYear/gPeakYear）在可分析階段會插入具體年份。
