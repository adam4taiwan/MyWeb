# 格局取格與用神方法論（定案 2026-07-09）

## 格局取格三步驟

```
步驟一：外格偵測
步驟二：比劫月 → 月刃格/建祿格
步驟三：八格取法（非比劫月）
```

### 步驟一：外格優先偵測

依序檢查以下外格（`LfDetectGeJuAndYongShen` 前段）：

| 外格 | 條件 |
|------|------|
| 化氣格 | 日干與鄰干合化（甲己化土/乙庚化金等），且月支配合、無破格 |
| 從殺格 | 日主在四柱地支無比印通根，官殺極旺 |
| 從財格 | 日主在四柱地支無比印通根，財星極旺 |
| 從兒格 | 日主在四柱地支無比印通根，食傷極旺 |
| 從強格 | 日主在四柱地支無比印通根，比印旺 |
| 從旺格 | 同五行占比≥75% |
| 曲直/炎上/稼穡/從革/潤下 | 三合或三會純一五行，天干無破格字 |

### 步驟二：月支本氣為比劫 → 月刃格/建祿格

```
月支本氣（LfBranchHiddenRatio[月支][0]）對日主 = 比肩 → 建祿格
月支本氣對日主 = 劫財 → 月刃格（陽干陰干皆適用）
```

**與步驟二的 LfYueLanBranch/LfJianLuBranch 查表關係：**
- Step 2 查表：處理陽干特定月支（甲卯→月刃，甲寅→建祿等）
- Inner格 block：處理陰干劫財月（如己日戌月→戊=劫財→月刃格）

**原則依據：**「比劫不能取格」= 比劫不能取**八格**，但月支本氣=比劫時，取月刃/建祿（外格機制）。

### 步驟三：八格取法（格局篇四則）

月支本氣非比劫時，從月支藏干中選取：

```
候選 = 月支藏干中排除比肩/劫財者

Rule 1：候選中 ratio 最高者（本氣）若透出天干 → 取之
Rule 2：本氣不透，取其他透出天干的候選（得令 siLingStem 優先）
Rule 3：皆不透，月令輕重較量（siLingStem 得令者最重，次 ratio）
```

**siLingStem（月令司令藏干）計算：**
```csharp
LfSilingTable["戌"] = { 辛:1-9天, 丁:10-12天, 戊:13-30天 }
// 入節天數 from birthSolarTerm（如「寒露第10天」→ 第10天 → 丁司令）
```

## 用神取法（LfGetYongShenCandidates）

基於格局 × 身強弱 × 命局組合，返回候選五行列表（優先序由前到後）。

### 月刃格（重點案例）

```
月刃格 when isWeak && caiHeavy  → [印, 比劫]   // 財重身弱→印比生扶
月刃格 when isWeak && guanHeavy → [印]          // 官殺重身弱→印護身
月刃格 when isWeak && shiHeavy  → [印]          // 食傷重身弱→印護身
月刃格 when isWeak              → [印, 比劫]
月刃格 when shiSanHe            → [財]          // 食傷三合成局→取財
月刃格 when caiHeavy            → [官殺]
月刃格 when guanHeavy           → [財]
月刃格 when shiHeavy            → [財]
月刃格 when inHeavy             → [財]
月刃格 when biHeavy             → [官殺]
月刃格                          → [官殺, 財]
```

**isWeak 門檻：bodyPct < 45%**

## 用神篩選三原則（LfPickYongShen）

候選中依以下優先序選取：

```
Tier1：有根 + 不空亡 + 不沖 + 不刑害（最優）
Tier2：有根 + 不空亡 + 不沖（有刑害，降級）
Tier3：有根但空亡
最後：全無根 → 月令旺相排序取最旺
```

同 Tier 內以月令旺相（王相休囚死）排序。
